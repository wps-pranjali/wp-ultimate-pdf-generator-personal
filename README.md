# wp-ultimate-pdf-generator

<h2 id="item-description__overview">Overview</h2>
<p><b>Are you in a search of PDF generating extension ? </b></p>
<p> WP Ultimate PDF Generator extension is a pdf generator for WordPress which is responsible for converting all posts, pages and products to PDF.
<p>Blog readers can export post into pdf and can print or send it to registered email address.</p>


<p><b>WP Ultimate PDF Generator</b> extension allows to convert the the post, pages and products in PDF.</p>

<p>This system enables you with a whole lot of features listed as: </p>

<h2 id="item-description__custom-post-types">Custom post types:</h2>
<p>It supports custom post types and print them in PDF.</p>

<h2 id="item-description__custom-meta-fields">Custom meta fields:</h2>
<p>It supports custom meta fields and print them in PDF.</p>

<h2 id="item-description__custom-fonts">Custom fonts</h2>

<p>Feature to set Custom fonts for PDF. Upload your own .ttf, .woff or .woff2 font, or install any Google Font, from Advance Settings &rarr; Custom Fonts. Fonts are stored in <code>wp-content/uploads/wp-ultimate-pdf-fonts/</code> so they survive plugin updates, and become available in every font dropdown and via CSS <code>font-family</code>.</p>

<h2 id="item-description__header">Header</h2>
<p>You can include header logo to pdf,Option to show site name,site description and site url.</p>

<h2 id="item-description__watermark">WaterMark</h2>
<p>Add watermark text and images to look PDF wonderful.
</p>

<h2 id="item-description__different-font">Different Font</h2>
<p>Can customize fonts of header and content..</p><p>

</p><h2 id="item-description__featured-image">Featured Image</h2>
<p>Can select to display featured Images.</p>

<h2 id="item-description__pdf-from-cache">PDF from Cache</h2>
<p>Have ability to generate pdf from cache to reduce load from server and can schedule backup of cache if Your blog is not updating too frequently and many more options
</p>
<h2 id="item-description__custom-css">Custom CSS</h2>
<p>Can add custom style to post contents,mostly all css supported..</p>

<h2 id="item-description__email-mode">Email Mode</h2>
<p>In email mode each pdf export link generate a popup window and visitor have to enter an email address to which the created PDF will be sent.</p>

<h2 id="item-description__cache-supporting">Cache supporting</h2>
<p>It provides the functionality to deliver the cached PDF to decrease server memory usage if cache is availabe in the system.</p>

<h2 id="item-description__acf-compatible">ACF compatible</h2>
<p>It is compatible with Advanced custom fields and supports all its meta fields.
</p>


<h2 id="item-description__minimum-requirements">Minimum Requirements</h2>

<ul>

<li>WordPress 4.0 or greater.</li>

<li>  WooCommerce 2.6.0 or greater.</li>

<li>  PHP version 5.5.6 or greater.</li>

<li> MySQL version 5.0 or greater.</li>
</ul>
